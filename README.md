## 🌿 Overview

This is a fully customized website for **Mother Touch Home Care**, a professional home nursing service based in Kerala, India. The site is designed to serve both local families and NRI families who need reliable, compassionate in-home care for their elderly or recovering loved ones.

The project started from a base design and was significantly extended with additional pages, features, UI improvements, animations, and content drawn from the official company brochure.

## ✨ Features

### Design & UI
- **Deep forest-green color theme** (`#0a5c44`) consistent with official branding
- **Cormorant Garamond + DM Sans** typography pairing — elegant serif headings with a clean sans-serif body
- Fully **responsive layout** — mobile, tablet, and desktop optimized
- CSS custom properties (variables) for consistent theming throughout
- Glassmorphism effects on hero card and care-plan panels

### Animations & Interactions
- **Scroll-triggered fade-up animations** on all cards and content sections using IntersectionObserver
- **Animated stat counters** in the hero section (Families Served, Verified Nurses, Availability)
- Morphing blob shapes in the hero background (pure CSS keyframe animation)
- **Floating card animation** on the hero service grid
- Hover effects with green gradient underlines on feature cards
- Navbar shadow transition on scroll

### Pages & Content
- **4 fully designed pages**: Home, About, Services, Contact
- Breadcrumb navigation on all inner pages
- 9-service grid with detailed descriptions on the Services page
- 4-step care plan process diagram
- 5-testimonial carousel/grid from real client locations across Kerala
- Contact form with service type selector and confirmation feedback
- WhatsApp quick-contact button

### Business-Specific Features
- **Free Assessment booking** CTA prominent on every page
- Emergency Replacement Guarantee highlighted as a trust signal
- **NRI-focused messaging** throughout (peace of mind for families abroad)
- Malayalam & English language staff highlighted
- Real contact details, email, and phone numbers from the brochure
- Dual phone number display with clickable `tel:` links

## 🛠 Tech Stack

| Technology | Purpose |
|---|---|
| HTML5 | Page structure and semantic markup |
| CSS3 | Custom styling, animations, CSS variables |
| JavaScript (Vanilla) | Scroll effects, counter animation, IntersectionObserver |
| Bootstrap 5.3 | Responsive grid, navbar collapse, utility classes |
| Font Awesome 6.5 | Icons throughout the UI |
| Google Fonts | Cormorant Garamond (headings) + DM Sans (body) |
| GitHub Pages | Static site hosting |

No build tools, frameworks, or dependencies beyond CDN-loaded libraries. The project runs entirely as static files.
